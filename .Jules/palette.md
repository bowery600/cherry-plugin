## 2026-07-05 - Server-Rendered Block Interactivity\n**Learning:** Filter buttons in server-rendered blocks ('render.php') often use basic inline JavaScript without relying on React or complex state management. ARIA states must be manually synchronized alongside visual classes.\n**Action:** When adding ARIA states (like 'aria-pressed') to interactive elements in 'render.php', ensure the accompanying inline JS is updated to toggle the ARIA attribute concurrently with the visual class (e.g., '.active').
