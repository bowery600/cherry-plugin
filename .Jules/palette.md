
## 2026-09-18 - Accessible Filter Tabs Pattern\n**Learning:** Filter buttons in server-rendered components (like portfolio-grid, resource-cards, page-communications) use `.chip` or `.filter-btn` with an `.active` class for state. They are currently missing `aria-pressed` states and some lack proper `role="group"` containers to announce the filter collection to screen readers.\n**Action:** When implementing filter groups in templates, define the container with `role="group"` and a descriptive `aria-label`. Add `aria-pressed="true"` to the active button and `aria-pressed="false"` to others, and sync this state with visual classes via JS.
