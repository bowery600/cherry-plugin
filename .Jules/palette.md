## 2024-07-01 - Portfolio Grid Accessibility
**Learning:** Implementing filter groups and toggle buttons in server-rendered templates (like render.php) requires specific accessibility attributes. It's crucial to define the container with `role="group"` and a descriptive `aria-label`, use `aria-pressed` to indicate active state, and sync the ARIA state with visual classes via inline JavaScript.
**Action:** Ensure these accessibility patterns are consistently applied when implementing or reviewing filter groups and toggle buttons in server-rendered blocks.
